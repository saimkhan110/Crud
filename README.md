# Product CRUD API

The project is in the Backend folder, alongside the category code.

Run: cd Backend, npm install, copy .env.example to .env, set MONGODB_URI, then npm run dev.

See Backend/README.md for endpoints and instructions. Import Backend/postman/Product-CRUD.postman_collection.json into Postman.

Verified: npm test in Backend passes HTTP CRUD and image cleanup tests using a stub database.
